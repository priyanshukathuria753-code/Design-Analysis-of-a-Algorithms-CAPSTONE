# Mini-Courier Planner (DAA Capstone - ETCCDA302)

## Files
- courier_planner.py  - full program
- data/parcels.csv    - sample parcels
- data/graph.csv      - sample road network
- outputs/            - run output, screenshot, runtime charts

## How to run
1. Install Python 3.8+ and matplotlib:  pip install matplotlib
2. Open a terminal in this folder
3. Run:  python courier_planner.py
